RECORDAR - FRONTEND (Proyecto-Investigacion_Frontend)
======================================================

ORDEN PARA ECHAR A ANDAR LA PAGINA EN LOCAL
  1. Encender MySQL.
  2. Encender el backend (carpeta Proyecto-Investigacion_Backend):   npm run dev
  3. Encender el frontend (esta carpeta):                            npm run dev

  Son DOS terminales abiertas al mismo tiempo: una para el backend y otra
  para el frontend.


CADA VEZ QUE QUIERA USARLO
--------------------------
  1. Con el backend ya encendido, abrir otra terminal en esta carpeta y ejecutar:

         npm run dev

  2. Abrir en el navegador:

         http://localhost:5173

  3. Dejar la terminal abierta. Se apaga con Ctrl + C.
     Los cambios en el codigo se ven solos al guardar, sin reiniciar.


SOLO LA PRIMERA VEZ (o en una computadora nueva)
------------------------------------------------
  1. npm install
  2. Copiar .env.example como .env
     (solo se edita si la API no esta en http://localhost:3000/api)


DIRECCIONES DE LA PAGINA
------------------------
  http://localhost:5173/                 Pagina principal (portada, modulos, catalogo y demas secciones)
  http://localhost:5173/#empresas        Lleva directo a una seccion (#proyectos, #internos,
                                         #externos, #servicios, #empresas, #convocatorias)
  http://localhost:5173/proyecto/1       Detalle de un proyecto (el numero es su id)
  http://localhost:5173/login            Inicio de sesion de administrador
  http://localhost:5173/admin            Panel: crear, editar y eliminar proyectos
  http://localhost:5173/admin/usuarios   Panel: dar de alta y gestionar administradores


DETALLES IMPORTANTES
--------------------
  - Los administradores se dan de alta en el panel, pestana "Administradores".
    El usuario siempre es un correo @itslerdo.edu.mx y la contrasena debe tener
    minimo 8 caracteres, una mayuscula, una minuscula, un numero y un simbolo.
  - Si no puedo entrar con ninguna cuenta, se crea o se le cambia la contrasena
    desde el BACKEND:
         npm run crear-admin -- <correo institucional> <contrasena>
  - La sesion dura 8 horas; despues hay que volver a iniciar sesion.
  - Debe abrir en el puerto 5173. Si Vite avisa que uso otro puerto (5174...),
    es porque ya habia otro frontend encendido: cerrarlo y volver a intentar,
    porque el backend solo acepta peticiones desde el 5173.
  - Si cambio algo en .env hay que reiniciar: Ctrl + C y otra vez npm run dev.
  - Las carpetas node_modules y dist NO se suben a GitHub (ya estan en .gitignore).
  - Los colores, tipografias y espaciados del diseno estan en tailwind.config.js.
  - Para que el icono de los proyectos se guarde, la base debe tener la columna ICONO:
    importar una vez database/03_icono_proyecto.sql del backend.
  - Textos de Servicios, Empresas y Convocatorias:   src/utils/modulosUtils.js
  - Contacto, redes, sitio oficial y banners:         src/utils/institucionUtils.js
    (para cambiar un banner: reemplazar la imagen en public/images)
  - La organizacion de carpetas esta explicada en ARQUITECTURA.md.


PROBAR LA PAGINA DESDE EL CELULAR (misma red que la PC)
-------------------------------------------------------
  Desde el celular "localhost" es el propio celular, por eso hay que usar la IP de la PC
  y cambiar 3 cosas. Se hace solo para probar; al terminar se deja todo como estaba.

  1. Conectar el celular a la misma red que la PC (zona Wi-Fi de Windows o el mismo Wi-Fi).
  2. Ver la IP de la PC: en PowerShell ejecutar  ipconfig  y copiar la "Direccion IPv4"
     (ejemplo usado en las pruebas: 192.168.1.6; con la zona Wi-Fi de Windows suele ser
     192.168.137.1). La IP puede cambiar al reconectarse: si deja de funcionar, repetir este paso.
  3. Cambiar los dos .env (cuidar que la IP este bien escrita, ese fue el error de las pruebas):
         Backend  (Proyecto-Investigacion_Backend\.env):
             CORS_ORIGIN=http://<IP DE LA PC>:5173
         Frontend (Proyecto-Investigacion_Frontend\.env):
             VITE_BACKEND_URL=http://<IP DE LA PC>:3000/api
  4. Reiniciar los dos (Ctrl + C y de nuevo). El .env solo se lee al arrancar, y el backend
     NO lo recarga solo aunque use node --watch.
         Backend:   npm run dev
         Frontend:  npm run dev -- --host
  5. Abrir en el celular (y tambien en la PC) http://<IP DE LA PC>:5173
     OJO: el backend solo acepta UNA direccion en CORS_ORIGIN. Con la IP puesta, abrir la
     pagina como localhost:5173 en la PC deja de cargar los datos; usar tambien la IP.
  6. Si la pagina abre pero no muestra proyectos, probar en el navegador del celular
     http://<IP DE LA PC>:3000/api/proyectos
         - Si no carga: Firewall de Windows. Abrir PowerShell como administrador:
             New-NetFirewallRule -DisplayName "Dev portal API" -Direction Inbound -Protocol TCP -LocalPort 3000,5173 -Action Allow -Profile Any
           y al terminar de probar quitarla:
             Remove-NetFirewallRule -DisplayName "Dev portal API"
         - Si carga el JSON: revisar F12 > Consola; "blocked by CORS" = CORS_ORIGIN no coincide
           exactamente con la direccion escrita en el navegador.
  7. AL TERMINAR devolver los .env a localhost y reiniciar los dos:
             CORS_ORIGIN=http://localhost:5173
             VITE_BACKEND_URL=http://localhost:3000/api
         y volver a usar  npm run dev  a secas en el frontend.


OTROS COMANDOS
--------------
  npm run build      Genera la version final en la carpeta dist
  npm run preview    Muestra esa version final para revisarla
  npm run lint       Revisa el codigo


SI ALGO FALLA
-------------
  La pagina abre pero dice "No se pudieron cargar los proyectos"
        El backend esta apagado, o MySQL esta apagado.
  En la consola del navegador (F12) aparece un error de CORS
        El frontend abrio en un puerto distinto al 5173 (ver arriba).
  "El usuario o la contrasena son incorrectos"
        Revisar mayusculas; si hace falta, cambiar la contrasena desde el backend.
  La pagina se ve sin estilos
        Falto npm install, o se borro postcss.config.js / tailwind.config.js.
  Al guardar un proyecto sale un error del servidor ("Unknown column 'ICONO'")
        Falta importar database/03_icono_proyecto.sql en MySQL.
  Me saca del panel y regresa al login
        La sesion expiro (8 horas) o se reinicio el backend con otro JWT_SECRET.
